# 生命周期与请求一致性

SubtitleSession已接入UniversalVideoAdapter创建的真实播放会话。Coordinator和SegmentationPipeline共用视频/轨身份，各自持有任务租约；停止销毁租约并发送作用域取消。Downloader使用独立Session，侧栏流式摘要保留自己的AbortController。后台依据sender.tab.id组合scope，取消在队列初始化/缓存await之前登记，标签页关闭清理所有相关作用域。实际RequestQueue和BatchQueue仍负责去重、引用计数、令牌桶与重试。

SubtitleTranslationPlan已接管translateSubtitles→enqueueSubtitlesTranslateRequest。配置、Provider、Prompt和上下文在前台拍快照；纯Prompt构造器同时用于缓存身份、批量执行和单条回退。后台校验新请求哈希；旧版本content消息只在入站时解析一次配置并重算缓存身份。不会将旧hash写到新Prompt结果上。播放摘要晚到只影响后续请求，现有批次持有自己的上下文值。

AI分段现在通过同一字幕RequestQueue执行，采用独立60秒超时和16384输出token预算，stop/start用generation与任务身份拦截旧返回/旧finally。原有时间轴验证保留。完整导出已有严格不完整文件拒绝逻辑保持，新增取消实际后台任务。

验证：既有字幕套件、快照/会话新增测试及真实队列契约测试；测试摘要见执行日志及最终报告。网络取消只能尽力发送AbortSignal，不能保证已收到请求的远程供应商不再计费。
