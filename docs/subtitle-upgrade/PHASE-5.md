# 显示与导出

Transcript使用完整cue身份配对，未变行复用引用；只在当前cue索引改变时更新活跃状态。超过200条时采用TanStack React Virtual的可测量可变行高列表，保持点击Seek、滚动后暂停跟随和返回当前字幕。新增依赖仅`@tanstack/react-virtual`及`virtual-core`，固定3.13.12；未增加AI框架。虚拟器组件明确退出React Compiler自动memo，避免可变实例被错误缓存。小列表保留原有DOM和滚动路径。

真实Chromium探索发现：50,000条原列表挂载P50 3009.9ms；尝试content-visibility后挂载1882.3ms但底部定位从37.8ms退化到786.5ms，因此撤销CSS方案。该探索原始数据保留在transcript-containment，不用它代表最终方案。最终虚拟列表及配对协议数据、分位数见最终报告。实际完整TranscriptSection功能测试8项通过：恢复位置、DOM数量、手动滚动、行点击、返回按钮、恢复跟随、变高译文、反向Seek。

完整导出保留2批×5条并发，独立Session、不可变配置、独立优先级与取消范围。新增结果身份多重集合校验，不能用“相同数量、非空但重复的结果”冒充完整文件。源轨先排序，非有限时间戳在模型调用前拒绝；最终输出排序，SRT继续规范化负值/零长时间但拒绝NaN/Infinity。失败结果不会作为原文伪译文静默下载。
