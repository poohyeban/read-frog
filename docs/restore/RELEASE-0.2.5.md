# Read Frog Lite 0.2.5

修复悬停翻译后，网站切换内容时仍保留上一段译文的问题。例如 YouTube 站内切换视频后，旧标题译文不应继续出现在新标题前。本版按原文 DOM 的有效性处理，不依赖特定网站或网址。

## 修复内容

- 网站改字、替换、移除或复用原文节点时，清理失效的悬停译文。覆盖双语、仅译文、分段文本及涉及的 Shadow DOM。
- 翻译请求尚未返回时原文已变化，丢弃旧结果的页面写入，避免刚清理完又补回旧译文。
- 清理保留网站的新内容和原始节点身份，不用旧内容覆盖整个区域。仅悬停模式不会因网页更新自动追加 API 请求，再次悬停才翻译新内容。
- 整页翻译开启时，保留原有自动重译流程。没有待处理任务或保留译文时释放监听，运行环境销毁时停止旧任务写入。

## 验证与边界

- 新增 21 项生命周期回归，覆盖文本修改、节点复用、迟到结果、Shadow DOM、仅译文恢复和整页翻译交接。
- TypeScript、Lint、271 个测试文件 / 2,626 项单元和协议测试，以及三组 Chromium 生产扩展回归通过。
- 浏览器用例实际加载生产扩展，在本地单页应用中复现“保留旧译文节点、替换原文、切换查询参数”，验证清理和再次悬停翻译；同时检查网页、划词、字幕、扩展上下文和凭据隔离。
- 浏览器测试使用本地页面与可控 API 响应，没有调用用户的真实 API Key。本版没有完成所有线上网站、浏览器和具体模型的兼容性验收，不能将上述回归等同于全部站点验证。

## 安装与升级

下载附件 `read-frog-lite-0.2.5-chrome.zip`，不要下载 Source code 作为扩展安装包。用解压后的文件完整替换原扩展目录，保持原路径，在 `chrome://extensions` 点击重新加载，再刷新已打开的网页。

没有新增依赖、浏览器权限或网络服务；没有修改配置和数据库格式。仍建议升级前导出配置和术语表，不要通过卸载重装升级。安装、开发入口、生命周期维护规则和手动验收步骤见 README。
