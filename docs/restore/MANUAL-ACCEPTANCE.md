# 人工验收：Read Frog Lite 0.2.0

这些是待执行步骤，不代表已在真实平台验证。使用 Actions 产物，不需要本地编译。记录浏览器版本、扩展 Commit、服务协议 / 模型、页面 URL、结果与控制台错误；报告时隐藏密钥。Chrome 和 Edge 分别执行。

## 安装与配置

1. 下载 CI Artifact，解压两层 ZIP，加载包含 manifest.json 的目录。确认名称 Read Frog Lite，没有登录 / Pro / Billing 入口。
2. 关闭官方服务的网络访问，打开 Popup、Options、翻译中心。扩展应正常启动，没有账户 / Billing 轮询。
3. 配置自己的 OpenAI-compatible Base URL、Key、模型；也可使用不需要 Key 的本地 HTTP 服务。选择各翻译功能 Provider。
4. 关闭设置页后重新打开、重启浏览器，检查语言 / Provider / 模型仍在。删除被选 Provider，应清空关联功能选择，不自动改用其他服务。未配置功能应提示配置，不发送请求。
5. 导出不含密钥的配置，检查没有 apiKey 或自定义 headers；带密钥导出只有明确选择时才进行，保管好导出文件。

## 网页与文字

1. 英文长文点击浮动按钮或 Alt+E，检查双语、句内链接、代码 / 数学、动态新段落。
2. Alt+Shift+M 切换仅译文，Alt+E 关闭，检查原文、标题、链接与布局恢复；重复开启 / 关闭。
3. 含 iframe / Shadow DOM 的页面重复上述步骤；长文滚动检查按视口翻译，停止后不再新增结果。
4. 选中文字 Alt+T，检查流式结果、更换 Provider、重新生成、复制、词典、句子分析与朗读按钮。
5. 启用悬停段落翻译，在设置中的修饰键按下 / 释放时检查只翻译所指段落。
6. 普通 input、textarea、contenteditable、实际使用的富文本编辑器连按三次空格，检查输入翻译；翻译未完成前继续输入，旧响应不得覆盖新输入；检查撤销。
7. 浮动按钮拖动、锁定、长按菜单、按站点禁用，刷新后检查位置 / 设置持久化。
8. 本地术语表添加术语及目标语言 / 站点范围，翻译时检查实际 Prompt 和结果。测试 CSV 导入导出、删除术语后的缓存失效。
9. 创建自定义 Action，设置 Prompt、Provider、字段、图标、快捷键，编辑 / 复制 / 删除 / 排序 / 取消固定，刷新后检查保存与实际执行。图标选择器使用本地集合。
10. 翻译中心默认只使用当前翻译服务。显式选两个 Provider 后应只向这两个端点发送文本，逐卡检查重试 / 复制 / 朗读。

## 原生视频字幕

1. YouTube 有原生字幕的视频与 Shorts、Netflix 当前可播放视频、X 含原生 TextTrack 的视频，手动开启字幕翻译。
2. 检查原文 / 译文 / 双语、换轨、时间同步、拖动进度、暂停、倍速、进入下一视频、全屏、字幕位置 / 样式 / 自定义 CSS。
3. 打开字幕侧栏、点击时间跳转、按住暂停、单词查询；请求视频摘要只应调用所选字幕 Provider。
4. 导出源字幕和译文 SRT，核对中文、多行、时间范围与未翻译行；断网 / 401 / 429 后重试并检查恢复。
5. 无原生字幕的视频应显示不可用，不提交官方 AI 任务，不宣称已经接入 ASR。Netflix 登录属于视频平台自身，不是扩展账户。

## 音频

1. Speech 选 OpenAI-style Provider，填写真实服务支持的音频模型与 Voice；预览、选区、原文、翻译中心分别播放。
2. 检查长文本分段衔接、预取、再次点击停止、不同文本替换旧请求、页面导航后清理；MV3 Service Worker 休眠后再次播放。
3. 调整语速、MP3/WAV、按语言 Voice；服务未配置、错误 MIME、超时、取消时应显示安全错误。没有原版不存在的暂停后继续操作。
4. ASR 当前没有 UI 捕获入口。开发集成时调用 `getTranscriptionProvider(config).transcribe({audio, format, language?, signal?})`，使用合法音频 Blob；检查 multipart 模型 / 语言、秒转毫秒、纯文本响应无伪造时间、取消与错误。不要将单元测试当成模型验收。

## 网络与隐私

1. 分别检查扩展 Service Worker、页面和 offscreen 的 Network。首次启动、打开设置不应查询 Read Frog 账户 / Billing / Hosted AI、Iconify CDN 或遥测。
2. 翻译与语音只请求已配置端点；本地服务可用 HTTP。服务 302 到另一个域时必须失败，目标域不得收到 Key。
3. 检查普通网页 DOM / data-* / window.postMessage、扩展公开日志、翻译错误提示都没有 Key。设置页密码输入属于用户主动管理凭据的扩展页面。
4. 服务端错误正文故意回显测试 Key，应只显示状态 / 安全提示；生产 ZIP 中不应存在该测试 Key。
5. 没有 microphone、tabCapture、identity、cookies 权限。字幕正常读取视频平台原生资源；禁止把页面自身的网络请求误归因于扩展。
