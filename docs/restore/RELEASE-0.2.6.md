# Read Frog Lite 0.2.6

本版整合网页翻译、Popup 和视频字幕的架构与性能升级，并修复发布前确认的缓存、导航和并发边界问题。

## 更新内容

- 网页翻译使用不可变请求快照、共享上下文和有预算的 DOM 更新；配置变化、导航和过期任务的资源按会话清理。
- Popup 并行加载必要状态、延迟加载可选资源；调整控件布局、Provider 设置和交互动画。导航或同 URL 重载后重新读取原标签页状态，并发读取不会取消有效的启停确认。
- 字幕会话贯穿队列、取消和结果校验；按时间区间检索当前字幕，恢复播放或 seek 后优先翻译当前位置，包含跨越 35:20 的长字幕。
- 字幕批量缓存以实际整批 Prompt、输入顺序、术语和 Provider 为身份；单项回退不污染多项批次缓存，保留所有有效共享订阅者的取消范围。
- 长字幕列表采用虚拟化渲染；完整 SRT 导出保持有界并发，核对 cue 身份、排序和完整性，避免下载残缺结果。
- 修复原生扩展回归发现的首次 SPA 导航后悬停译文被误丢弃，以及扩展重载时失效的存储监听清理阻断原生字幕恢复的问题。

## 验证范围

发布前，本地 300 个测试文件、2783 项测试，以及类型、静态、格式检查和 WXT 生产构建通过；Chromium 受控浏览器回归覆盖 Popup、字幕恢复/seek、队列和完整 SRT 导出。新增本地浏览器回归使用真实 DOM 和生产悬停翻译路径，确认导航后的第一次翻译可完成；撤回对应修复时，该断言失败。存储监听清理异常也有修复前失败、修复后通过的单元回归。详细基线证据见 [边界审查报告](../lite/RELEASE-BOUNDARY-REVIEW.md)。

[CI 41063974203](https://github.com/poohyeban/read-frog/actions/runs/41063974203) 的 300 个测试文件、2783 项测试、类型/静态检查、生产 ZIP 以及全部 4 项浏览器回归通过。原生 MV3 受控夹具验证了 SPA 导航后首次悬停翻译、35:20 异步续播、35:00～35:40 长 cue、扩展重载后的原生字幕恢复和页面刷新后恢复翻译。Shadow DOM 单元测试等待分段调度完成，并强制跨时间片执行，避免机器负载导致过早断言。

本地环境管理策略禁止加载 unpacked 扩展，因此这些检查不能冒充真实 MV3 或所有线上平台验收。真实 YouTube、Netflix、X.com、广告与字幕轨切换、自然 Service Worker 休眠/唤醒等人工场景仍须按 [验收步骤](../lite/MV3-MANUAL-ACCEPTANCE.md) 完成。CI 原生扩展夹具使用受控页面和模型响应，也不等同于所有真实站点兼容性测试。

发布仅使用本次成功 CI 的原始生产 ZIP，校验 Manifest、许可证和 SHA256；该 ZIP 与本地验证产物逐字节一致。实际构建来源及校验值记录在 [构建指标](metrics-0.2.6.json)。

## 安装与升级

下载 Assets 中的 `read-frog-lite-0.2.6-chrome.zip`，不要使用 `Source code` 作为扩展安装包。解压后完整替换原扩展目录，保持原路径，在 `chrome://extensions` 重新加载，再刷新已打开的网页。附件 `SHA256SUMS.txt` 用于校验。

升级前可导出配置和术语表；不需要卸载重装或清空数据库。本版没有增加扩展权限。旧的单条字幕 LLM 缓存不再用于批量请求，由已有缓存清理机制回收。
