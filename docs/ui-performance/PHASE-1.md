# 阶段 1：启动及资源加载

配置/主题/语言就绪即可挂载；tabs 与后台状态独立并行，页面控件在未知状态禁用。tabs 仅捕获一次，网站状态派生自 captured URL + 当前配置。页面状态失败有 2.5 s 超时和重试；命令应答只表示已转发，UI 必须从已有后台协议确认实际启停，最多每 100 ms 复查并有总时限。关闭时停轮询、解绑状态存储监听，晚到响应不能重写新状态。

HTML 页面按需加载选择的本地 locale，英文静态 fallback；其他上下文仍同步打包。生产 background.js 检查无 `import(`，manifest 与基点完全一致。Provider 面板按需加载并在 pointer enter/focus 预热。保留原配置写队列及 mount 同步读取，避免破坏竞态保护。

生产静态 JS：Popup 1,117,090 B（基线 1,802,425 B，-38.0%）；Options 1,026,917 B；Hub 2,411,696 B。选中非英语还会加载对应 locale chunk，最终报告分别说明。2×4 次浏览器 smoke 只验证可运行，不作为性能结论（与 lint 并行发生 CPU 竞争）。最终使用独占测量的 30×4 组数据。

针对会导致错误页面状态的时序测试 5 项通过；LocaleBoundary 3 项通过。类型/静态检查与生产构建通过。没有 push、PR 或 Actions。
