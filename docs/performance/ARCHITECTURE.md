# Architecture audit

Baseline: 0.2.5 at `18f2c8cbfddc3df5e4b7552a48b1731c28ac4cfd`. The original 0.2.4 worktree was preserved. Fresh baseline install/build/test evidence is in [baseline.json](baseline.json).

The [inventory](audit-inventory.json) enumerates tracked files and production runtime import edges, with review depth explicitly marked. 718 production TS/JS modules and 2,814 local runtime edges were checked after the changes. Changed hot paths were read and regression-tested; unchanged modules received import/build/dependency review. This does not claim a line-by-line manual reading of every asset, locale, test or unchanged source file.

## Findings and changes

| Area                | Finding                                                                                                                                             | Resolution and evidence                                                                                                                                                                       |
| ------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Request correctness | Provider reference already carried a snapshot, but model selection and prompt construction could reread configuration                               | Reuse the existing provider reference, explicit prompt templates and verified v2 cache/group identity. Capture, queue/retry, glossary and stale-message tests; no second credential snapshot. |
| Resource ownership  | Error auto-hide timer survived subtitle stop; MessageChannel ports were not explicitly closed; interrupted host startup could install late bindings | Separate fixes with reproductions. Disposal marks the session inactive before awaiting more work; context-invalid stop avoids notifying a dead runtime.                                       |
| Audio ownership     | An unmounted TTS component could start late synthesized audio                                                                                       | Owner cleanup cancels synthesis/playback and late results cannot resume the run. Native protocol and supersession regressions retained.                                                       |
| Dynamic DOM         | Mutation roots were synchronously traversed repeatedly                                                                                              | Set-based ancestor coalescing, serial cancellable scan slices, session/source/connection checks. Preserve immediate invalidation, carry and cleanup.                                          |
| Hover / Shadow DOM  | Repeated unit-by-mutation ancestor walks and strong observer retention                                                                              | Pre-index mutation ancestors/removals once; Map-based observer registration/release, including detached/reused roots and pending records.                                                     |
| Requests            | Burst capacity was not concurrency; timeout retries could overlap an uncooperative attempt                                                          | Independent attempt slots, cleanup symbols, bounded settlement grace, no overlapping timeout retry; backoff/token wait releases slots. Slot notifications wake pending batches.               |
| Subtitle ticks      | Repeated linear lookup; order-sensitive overlap rules                                                                                               | Start/prefix-max-end index; differential testing against the original linear predicate, unsorted fallback and track-version rebuilds. Map-based same-start merge and unchanged cue reuse.     |
| UI subscriptions    | Structured storage clones notified unrelated config consumers                                                                                       | Deep-equal field selection. Popup profiler shows elimination of these unrelated commits.                                                                                                      |
| Editors             | New extension/setup arrays forced CodeMirror reconfiguration                                                                                        | Stable static configuration. Advanced fields mount/load on first expansion; keep mounted afterwards to preserve drafts and autosave.                                                          |
| Transcript          | Each translated-cue update recreated unchanged rows                                                                                                 | Reuse equal row/array identities through a Jotai selector; active time lookup separate from track rebuilding.                                                                                 |
| Layering            | Text execution imported Toast; config constants pulled Jotai through a merge helper                                                                 | Toast adapter separation; pure merge and storage adapter in config layer. Source and built-content-script checks now guard these boundaries.                                                  |

The existing glossary matcher, priority heap, routing lazy loads, 50-row glossary pagination, AI SDK adapters, rich-text/editor compatibility and offscreen audio controller were retained. Broad rewrites were not justified. Translation Hub receives the shared config/model corrections; no speculative Hub rendering rewrite was added without a distinct measured benefit.

## Audit limits and remaining acceptance

- Managed Chromium blocks installation of this extension. Production extension UI/CPU/heap profiles, full browser regression and a faithful visual demo cannot be completed locally. Subsequent GitHub CI passed all three automated production browser scenarios; see VALIDATION.md. Existing YouTube Service Worker, context-invalid, protocol and data-compatibility checks remain in the regression suite and PR workflow.
- The 30-minute resource measurement covers the Node queue only. It is not evidence of 30-minute browser DOM, ShadowRoot, subtitle, TTS or offscreen heap stability. Repeated lifecycle tests cover deterministic cleanup, not GC reachability under real browser load.
- Production scenarios still requiring permitted-browser acceptance include large-page long tasks, SPA/focus/keyboard behavior, route switching, large glossary interaction, sustained subtitle following, and audio/offscreen navigation cycles. Do not infer their P95 from JSDOM.
- Nonliteral dynamic imports and generated WXT modules are reported/validated through build and tests, not fully resolved by the import checker.
- Dependency and architecture decisions, retained exceptions, ownership and development rules are in [TECH_STACK.md](../../TECH_STACK.md).
