# Read Frog Lite 0.2.5 性能优化预览版 1

这是基于 0.2.5 的性能与架构优化预览版，供安装验证。未合并 PR #8，不替换正式版 v0.2.5。

## 本次内容

- 固定翻译请求的 Provider、Prompt、术语及缓存身份，避免配置变更后请求与缓存归属不一致。
- 合并重复 DOM 扫描根，按时间片调度；改善悬停译文、Shadow DOM 观察器、字幕和 TTS 的资源清理。
- 请求并发槽与令牌桶突发容量分离，完善取消、超时、重试和 429 行为；保持既有限速设置和默认并发行为。
- 字幕采用前缀最大结束时间与二分索引，保留原数组第一条重叠字幕、时间间隙及跳转语义。
- 缩小 UI 状态订阅，复用字幕行与编辑器配置，延迟高级 JSON 编辑器初始化；整理依赖和核心/UI 边界。

## 验证与已知边界

277 个测试文件、2,675 项测试，以及三组真实 Chromium 扩展回归通过。复用 [CI 40914031459](https://github.com/poohyeban/read-frog/actions/runs/40914031459) 的原始 ZIP，不重新构建。

算法工作量和部分无效渲染已得到改善；生产导航耗时尚未确认稳定改善，也不能排除小幅启动回退。真实 Provider 负载、完整视觉检查及 30 分钟浏览器 DOM/TTS/offscreen 内存验证尚未完成。因此标记为 **Pre-release**，不设为 Latest。

## 安装

下载附件 **read-frog-lite-0.2.5-perf.1-chrome.zip**，不要用 Source code 作为扩展安装包。解压后完整替换原扩展目录中的文件，保持原目录路径，在 `chrome://extensions` 点击重新加载，再刷新已打开的网页；不要通过卸载重装升级。

为了复用已验收产物，扩展 manifest 中的版本仍为 **0.2.5**；GitHub 标签 `v0.2.5-perf.1` 用于区分本次预览。未改变扩展权限、Provider 协议及配置/数据库格式。翻译缓存使用新的身份命名空间，保留旧缓存和用户数据。
